# MoonDesk 0.1.0 Preview 4

Status: release candidate; not published.

## Highlights

- Clearer first-run library selection and honest optional-service setup.
- Typed loading, empty, ready, stale, and recoverable states across primary
  work surfaces.
- Shared keyboard-accessible application landmarks and destination status.
- Expanded four-viewport, large-text, keyboard, and durable restart evidence.
- Portable release manifests, strict artifact hashing, and immutable unsigned
  preview automation.

## Compatibility

- Architecture: macOS arm64 (Apple silicon)
- Minimum macOS version: 11.0
- WebView: system WKWebView

## Unsigned preview boundary

The automated preview artifact is unsigned and not notarized. It is intended
for internal acceptance, not general production installation.

## Verification required before publication

- Clean pull-request and push validation runs.
- Passing version-tag unsigned-preview workflow.
- Independent artifact verification against `SHA256SUMS`.
- Original-resolution UI evidence review.

The final artifact hash is intentionally absent until a retained remote build
exists. Publishing this note requires a new immutable artifact and recorded
checksum.
