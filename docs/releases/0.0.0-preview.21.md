# MoonDesk 0.0.0 Preview 21

Unsigned macOS QA preview for the Code request-to-review workflow.

## Changes

- Keeps Code conversations, Git changes, source editing, local review, and GitHub PR review in one MoonBook workbench.
- Opens a remote PR at its verified head in an isolated worktree without replacing the source checkout.
- Groups large PR file lists by directory, supports path filtering, and keeps the selected diff and exact-line comment anchor visible.
- Saves PR conversation and line drafts locally; checks the live PR head and line before any public post. Timed-out PR file loads have an in-place Retry action.
- Localizes checkout failure, preserves its exact-head retry action, and keeps the review controls readable at phone width.
- Carries ordered text and image turns through MoonClaw's canonical journal, and shows run, skill, and schedule evidence from their owning services.

## Validation

The local exact-commit preview at `720cf267` passed release identity, five-file checksums, nonhosted channel validation, and packaged UI comparison. Its native Mac window opened PR #6 at the exact head, loaded 270 files in directory groups, filtered to one file, selected a new-file line, and saved then discarded a local draft without posting. Earlier connected QA posted a top-level and exact-line comment to a disposable PR and verified stale-head refusal.
