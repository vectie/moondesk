# MoonDesk 0.1.0 Preview 13

This preview integrates MoonDesk with the exact MoonFind-to-MoonFlow execution
boundary while preserving MoonDesk as the human desktop and composition
surface.

## Changes

- Accepts only `moonsuite.work-model.v1` from the selected MoonBook and never
  lets a draft graph shadow executable work.
- Resolves a digest-pinned `moonflow.capability-catalog.v1`, validates the
  compiled graph, and imports only through MoonFlow's conformant import.
- Binds saved composition to graph identity, source digest, and declaration
  revision, with deterministic compiled identities and safely rebased
  suite-relative artifacts.
- Persists the catalog snapshot, validation report, and import receipt while
  leaving run events, projections, scheduling, recovery, and control mutations
  under MoonFlow ownership.
- Presents exact operation, schema, authority, claim, adapter, review, and
  health evidence without treating installed-product inventory as readiness.
- Removes product-specific continuation semantics and derives continuation
  from graph dependencies and MoonFlow runnable projections.
- Adds dynamic canvas bounds and a visible Fit control for the 63-stage
  MoonFind robotics reference.

## Compatibility

- macOS 14.0 or newer on Apple Silicon.
- Unsigned preview; not Developer ID signed or Apple-notarized.
- Local single-user alpha.

## Known release blockers

This preview is not a production-ready release. It still requires
Developer ID signing, notarization, Gatekeeper and clean-machine evidence,
update and rollback qualification, live host-generated capability health, and
the frozen lifecycle soak.
