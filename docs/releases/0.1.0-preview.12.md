# MoonDesk 0.1.0 Preview 12

This preview completes the repository-owned productization work through the
release qualification path while keeping the release boundary explicit.

## Changes

- Completes first-class DOCX, XLSX and PPTX editing for the supported fidelity
  contract, including save and reopen verification.
- Completes direct Code open, edit, save, diff, reload and conflict-preserving
  replacement.
- Keeps the primary navigation as Desk, Wiki, Code, Flow and Packs, with
  operational views under their owning surface.
- Completes the repository-local localization, keyboard, reduced-motion,
  accessibility-tree and responsive-layout gates.
- Records package ownership, workspace confinement, generated-content
  isolation, runtime evidence and durable approval boundaries.
- Adds immutable preview identity/channel metadata, release verification,
  protected credential inputs and explicit clean-machine, lifecycle and soak
  evidence contracts.

## Compatibility

- macOS 14.0 or newer on Apple Silicon.
- Unsigned preview; not Developer ID signed or Apple-notarized.
- Local single-user alpha.

## Validation

- MoonDesk native: 338 tests passed.
- MoonDesk UI: 501 tests passed.
- Localization: 6 tests passed.
- Release verifier: 8 tests passed.
- Phase 9 non-credentialed release smoke and production UI build passed.

## Known release blockers

This preview is not a production-ready release. Warning-clean hosted CI,
Developer ID signing, notarization, Gatekeeper, clean-machine
install/update/rollback/removal and the frozen 24-hour soak still require
retained evidence. See
[`FINAL_RELEASE_READINESS_2026-07-30.md`](../FINAL_RELEASE_READINESS_2026-07-30.md).
