# MoonDesk 0.1.0 Preview 11

This preview makes MoonClaw installation and first-run setup reliable on a
clean Apple Silicon Mac and adds the MoonGate connection path.

## Changes

- Initializes MoonClaw's canonical configuration directory before installing
  and starting its managed service.
- Distinguishes installation, repair, stopped, running, and
  running-without-a-model states.
- Adds explicit Codex OAuth, GitHub Copilot authorization, and OpenRouter key
  setup from MoonDesk.
- Installs MoonClaw 0.1.5 and waits for daemon and model readiness instead of
  treating process startup as sufficient.
- Supports MoonGate binding through MoonClaw's provider configuration while
  preserving unrelated providers and the user-owned primary model.
- Keeps service, platform, process, installer, and authority diagnostics behind
  the technical-details disclosure.

## Compatibility

- macOS 11 or newer on Apple Silicon.
- Ad-hoc signed and not Apple-notarized.
- Uses the existing trusted HTTP release origin; HTTPS migration is deferred.

- MoonGate: 849 tests passed.
