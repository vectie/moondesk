# MoonDesk 0.1.5 desktop package

This packaging release adds the current MoonDesk Lepusa macOS application and
disk image to the hosted release.

## Included

- Current Rabbita desktop UI and MoonBit host from the tagged source.
- Lepusa-packaged MoonDesk application, ZIP archive, release manifest, and DMG.
- SHA-256 release evidence generated and verified by the canonical release
  tooling.

## macOS

The artifact targets Apple silicon and macOS 11 or newer. It is ad-hoc signed
because no Developer ID Application identity or notarization profile is
installed on the release machine. If Gatekeeper blocks the first launch,
Control-click MoonDesk and choose **Open**.
