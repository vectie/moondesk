## 当前采用的决定

1. 目标是高质量交付，自顶向下推进，默认一个主 Agent。
2. 授权范围内从理解、执行、验证、修复到交付自主完成，内部错误优先自行恢复。
3. hardening 只保证必要的执行事实与权限边界，不把正常工作变成逐步审批。
4. 不采用常驻 Router 加 Worker 的双 Agent 默认架构；不新增 Reviewer 或 Watchdog Agent。
5. 保留现有 loop、journal、continuation、工具结果与 finish，合并完成判断。
6. 删除旧 Goal、双 authority、重复验收与前端推断；以实际调用关系确定最终删除范围。
7. 不考虑旧协议、旧格式和旧 UI 兼容；不安排双写或旧会话迁移。
8. 多删不必要代码，精简架构，少增实现；不新增通用 runtime 框架、检查器注册系统、Operation 数据库或 submit_candidate 工具。
9. 取消默认完整验收流水线与普遍隔离快照，验证按任务性质和实际后果选择。
10. 当前内容是设计与计划。此前讨论未实施运行时代码改造。
