几个容易混淆的来源：

- **同一轮没有完全相同的重复消息**，24 个请求的该项计数都是零。累计重新发送旧源码属于这条无状态调用路径的成本，不能简单把过去的工具结果删掉。
- MoonCode 整份测试和源码正文累计 **31,256**；Pi 的相关 grep 与源码为 **19,344**。多出的 **11,912**主要是读取范围不同，不能声称框架把同一个文件重复读了十次。MoonCode 测试读取是一次，在十个后续请求中出现。
- MoonCode 的技能正文累计 **4,807**，Pi 没有这部分。本次不是又加载了完整长技能；现有短入口仍完整保留，不引入强制摘要。
- 命令／诊断正文为 MoonCode **11,720**、Pi **3,053**。Native、Git 环境错误、outline 和实际检查结果等在后续上下文中持续占用空间。它们有失败事实，不能为了账面降本从日志中隐去。
- **17 个工具对 4 个工具**的 schema 是固定差额的重要来源。但不能为了这个样本就隐藏浏览器、图片、补读、技能或其他有效能力，也不按用户词语新建工具路由。

## 已实施的最小修改

1. **工具结果不再把源码／日志正文再编码成 JSON 字符串。** 复用现有 model result producer，发送一行 JSON 状态／引用头，再跟原始正文。退出码、错误、截断、文件版本与 retained artifact 引用保留；删除已重复的 sandbox 配置标志、内部路径／编辑前指纹和审计字段。canonical journal、UI 事实、完成证据仍保留完整结果。现有 context compiler 只需从首行取 `evidence_ref`，没有新协议分发器或存储层。
2. **删除第二份读／错误索引及专属测试。** 现有 transcript 已有观察、错误和调用参数，压缩后已有结果范围和 `read_result` 可补读。保留它们，删除每轮重建、追加索引的代码。Task 前缀省去空数组、空对象、空个人偏好、空 Book instructions，以及没有 passage 的检索说明；真实约束、文档、查询结果和任务修订保留。
3. **已知没有 MCP 连接时，不发送两个无实现可用的 MCP 工具定义。** 复用既有 `available_mcp_integrations`，不新增发现过程。未知配置继续保留工具，已有连接和显式 allowed-tools 也保留。此次实际 Book 从 17 个工具变为 15 个；其他有效能力没有为跑分隐藏。
4. **删除 edit 两种字段的互斥拒绝。** 明确为先执行顶层 `old_string/new_string`，再顺序执行 `edits`，统一复用现有原子替换。任一步不匹配仍不落盘，没有新增重试、计划替换或强制 read。实际第六轮调用已经表达了两个明确修改，却被要求换一种格式再发一次；无需建立新状态处理它。

第六轮真实混合参数已在原始源码上离线重放：先复现第一处修改，再原样执行原来被拒的调用，所得文件与原第七轮之后、已独立验收的交付文件**逐字相同**。现有测试同时验证混合编辑的顺序和失败时整份文件不变。不将这一事实冒充已经观察到新的模型决策或减少一次计费请求。

## 续优化：修掉默认工具失败，而非再删必要上下文

继续只使用已有日志和本地执行器，不付费重跑。原第三轮 `moon_cmd` Native 与第十轮 Git 的 `xcode-select` 错误可在本机原样复现，不能只归为模型没有抄全环境变量。

Fort 已允许 `/private/var/select` 和实际开发工具目录，却没有允许查询 `/var` 系统别名的元数据。系统工具选择器因此把路径解析失败报为 `Operation not permitted`，不能进入正常的默认工具选择。离线对照中，仅补 `/var` 的 `file-read-metadata` 即让默认 clang 成功；只允许最终 `/var/select/developer_dir` 仍失败。Git 随后暴露宿主 `/etc/gitconfig` 拒绝，系统 attributes 也会产生重复警告。

生产修改仅在已有 Fort macOS policy/environment **增加三行**：允许 `/var` 本身的路径元数据，并设置 `GIT_CONFIG_NOSYSTEM=1`、`GIT_ATTR_NOSYSTEM=1`。没有继承宿主环境、读取额外目录、发现工具链或增加重试。保留一个真实系统 Git/clang 回归，删除临时诊断测试；删去默认 Native 必须逐次补 Shell 环境的过时配置说明。

使用原真实 MoonLib 仓库、原 executor 配置、相同授权和沙箱边界，本地重新执行默认 `Exec moon test --target native --frozen`：**108/108 通过**；默认 `git diff --check`、status、stat 成功，不再需要显式编译器／Git 环境，也不再有宿主 Git 配置／attributes 警告。原源码、测试及历史成本不变。这是工具执行回归，**不是新的完整 Agent 交付或更少模型轮次的证明**。

Fort 全量 Native 最终 **300/300**，真实系统工具回归通过，`moon info`／`moon fmt` 已运行，公开 `.mbti` 不变；恢复 formatter 引入的无关语法迁移。首次并行全量为 299/300：原有 250ms 子进程超时测试未读到 PID；未改该测试或期限，单独复查通过，串行全量 300/300。临时诊断最初有文件过滤器和 fixture 授权配置错误，修正后才得到上述真实红绿结果，均未调用模型。
