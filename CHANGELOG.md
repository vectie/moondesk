# Changelog

MoonDesk records user-visible changes here before release. Released entries and
their linked release notes are immutable; corrections are published as a new
version.

## Unreleased

- Replaced legacy Flow graph import with exact catalog validation and conformant
  MoonFlow import, added digest-bound evidence and delegated controls, and made
  the generic composition canvas fit and inspect the complete 63-stage
  MoonFind reference graph.
- Made MoonClaw first-run installation initialize its canonical configuration
  before starting the daemon, with explicit install, repair, authentication,
  model-readiness, and retry states.
- Added MoonGate-managed MoonClaw provider binding without replacing unrelated
  MoonClaw providers or taking ownership of the user's primary model.
- Added a shared accessible application shell with skip-to-content,
  destination landmarks, semantic current navigation, and typed live status.
- Made release metadata portable and added strict artifact verification,
  immutable unsigned-preview automation, and terminal packaging failures.
- Hardened first-run library selection, capability setup, typed surface states,
  keyboard journeys, responsive layouts, and durable browser-host evidence.
- Simplified Home Code-assistance setup copy and moved service, platform,
  process, installer, and authority diagnostics behind `Technical details`.
- Localized the ordinary six-state Code-assistance experience in English and
  Simplified Chinese, with reproducible generated catalogs and exact
  accessibility-attribute translation. Its complete 26-string UI slice now
  carries explicit source-owned keys with exact source/catalog/runtime parity.
